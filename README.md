# Лабораторийн ажил 1: Playwright автомат тест

**Оюутны нэр:** А.Адъяахүү
**Оюутны код:** B232270125

## Юу хийснээ

- Ubuntu (WSL2) орчинд Node.js (nvm-ээр) болон Playwright төсөл суулгасан.
- `tests/mytest.spec.ts` файлд saucedemo.com дээр 3 тест бичсэн:
  1. Амжилттай нэвтрэх (`toHaveURL`, `toBeVisible`, `toHaveText` assertion-тай)
  2. Буруу нууц үгээр нэвтрэх сөрөг тест (алдааны мессеж шалгана)
  3. Бараа сагслах (сагсны тоо болон сагс доторх бараа шалгана)
- Нэвтэрсэн тест бүр logout хийж төгсдөг. Тест хоорондоо хамааралгүй, дангаараа ажилладаг (test isolation).
- Locator-оор голчлон `getByRole`, `getByPlaceholder` ашигласан. Зарим элементэд (алдааны мессеж, сагсны тоо) `data-test` атрибутаар `locator` ашигласан.
- Trace-тэй ажиллуулж, тестийг санаатайгаар унагаад trace viewer дээр алдааг ажигласан.
- `video: 'on'` тохиргоотой ажиллуулж, бичлэг болон HTML тайланг `evidence/` хавтсанд хадгалсан.

## Ажиллуулах

```bash
npm install
npx playwright install
npx playwright test
npx playwright show-report
```

## XPath-аас зайлсхийх шалтгаан

XPath нь хуудасны DOM бүтцэд хэт ойр холбогддог тул дизайн бага зэрэг өөрчлөгдөхөд тест эвдэрнэ. `getByRole` зэрэг locator нь хэрэглэгч хуудсыг хэрхэн хардагтай (товч, холбоос, нэр) нийцдэг тул уншихад хялбар, тогтвортой, мөн хүртээмжийн (accessibility) бүтцийг хамт шалгадаг. Энэ лабораторид `Logout` нь `link` биш `button` role-той байсныг page snapshot-оос олж засаж, үүнийг бодитоор харсан.

## Codegen-тэй харьцуулсан дүн

`npx playwright codegen saucedemo.com` нь миний хийсэн үйлдлүүдийг код болгон бичиж өгсөн. Гарсан код нь ихэвчлэн `getByRole`, `getByPlaceholder` ашигладаг. Гэхдээ assertion (`toHaveURL`, `toHaveText`), logout хийх алхам, тайлбар коммент орохгүй тул тэдгээрийг би өөрөө нэмсэн.

## Playwright ба Selenium-ийн ялгааны талаарх ажиглалт

Playwright-ийг суулгахад нэг командаар хөтчүүд (Chromium, Firefox, WebKit) хамт суусан бөгөөд тусдаа driver татаж тохируулах шаардлагагүй байсан. Элемент гарч ирэхийг Playwright автоматаар хүлээдэг тул тестэд гараар sleep эсвэл explicit wait бичих хэрэггүй байлаа. Тест унахад алдааны мэдээ нь ямар locator дээр гацсаныг шууд харуулж, page snapshot нь `Logout` нь `link` биш `button` байсныг тодорхой харуулсан. Trace viewer нь алхам бүрийн дэлгэцийн зураг болон үйлдлийг буцааж харах боломж өгсөн нь алдаа олоход маш хурдан байлгасан. Video бичлэг нь тест яг юу хийснийг нүдээр харуулж, тайлагнахад тус болсон. Selenium нь олон хэл, олон хөтөчийг дэмждэг, олон жил хэрэглэгдсэн томоохон экосистемтэй гэдгийг ойлгосон ч WebDriver болон тусдаа driver-ийн тохиргоо шаарддаг, хүлээлтийг өөрөө зохицуулах хэрэгтэй гэж судалж байхдаа ажигласан. Миний хувьд Playwright нь тохируулга бага, тогтвортой ажилладаг, алдааг шинжлэх хэрэгсэл нь өгөгдсөн тул шинээр эхэлж буй хүнд илүү хялбар санагдсан. Харин Selenium-ийг бодит төсөлд ашиглаагүй тул хоёрыг гүнзгий харьцуулж чадахгүй.
